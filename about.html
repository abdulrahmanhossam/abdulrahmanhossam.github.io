About

I’m Abdulrahman Hossam, a backend and systems software engineer based in Cairo, Egypt. I build deployment platforms, Clean Architecture backends, and open-source developer tools at Ofuq and Tawjjeh.

My work spans architecture, domain modeling, runtime internals, and deployment tooling. Recent projects include single-host deployment control planes in .NET 10, native Rust desktop rendering engines, and zero-dependency NuGet libraries. I care about keeping systems predictable under load and readable down to the memory layout.
